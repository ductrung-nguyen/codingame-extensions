# Icon Assets

This directory stores the icon set referenced by `manifest.json`. The actual PNG/SVG files are intentionally omitted from this repository; add the following sizes before packaging the extension:

- `icon-16.png`
- `icon-32.png`
- `icon-48.png`
- `icon-128.png`

Each icon should use the same visual motif (e.g., CodinGame logo overlay with sync arrows) for consistency across Chrome surfaces.
