ℹ️ How to get your authentication token:

✨ Easy Method (Recommended):

  1. Open VS Code with the CodinGame extension installed
  2. Click the CodinGame icon (graph) in the Activity Bar (left sidebar)
  3. Find the "Bridge Status" panel at the top
  4. In the "🔑 Authentication Token" section, click the "📋 Copy Full Token" button
  5. Paste the token in the field above
  6. Click "Save Settings" to connect

📝 Alternative Method (Output Panel):

  1. Open VS Code's Output panel (View → Output)
  2. Select "CodinGame Bridge" from the dropdown
  3. Look for the line: [BRIDGE] Auth token: [64-character hex string]
  4. Manually copy the full 64-character token
  5. Paste it above and click "Save Settings"

💡 Tip: The Copy Token button in VS Code is the fastest and most reliable way to get your token!

⚠️ Security Note: This token is used to authenticate the Chrome extension with your local VS Code instance. Keep it private and do not share it. The connection only works on your local machine (127.0.0.1).
